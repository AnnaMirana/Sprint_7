# Sprint 7 — Distinguer les verbes HTTP

**Objectif du sujet :** "distinguer les methodes des requetes http. une methode
et une url est associe a get post, put, delete".

**Ce qu'apporte ce sprint :** `GET.java`, `POST.java` + `VerbUtil.getVerb()`
(reproduit `Outil.getVerb()`), et la detection de duplication de verbe sur une
meme URL.

**Note :** seuls GET et POST sont presents dans le code source que tu m'as
transmis — PUT et DELETE, mentionnes dans le sujet, n'ont pas ete trouves.

**Pour tester :** `cd sprint7/test && javac *.java && java TestSprint7`
